# 政策智答 · AI 智能工作台方案与原型

这是一个 AI 产品方案设计与交互原型项目，以党政机关的政策问答为业务场景，探索如何通过统一对话入口、技能广场和知识库管理，帮助工作人员查询政策、核对原文及整理办理材料。

本项目包含软件设计方案、可交互的网页原型和带截图的功能演示文档，用于展示从产品设计到业务流程验证的完整思路。

## 项目内容

- [政策问答智能工作台设计方案](党政机关政策问答智能工作台设计方案.pdf)：业务流程、知识入库、检索问答、引用追溯、版本管理及技术设计。
- [原型介绍与功能演示](政策智答交互原型介绍与功能演示.pdf)：配合实际界面截图说明操作流程。
- [交互原型](政策智答_交互原型演示包/政策智答_交互原型)：网页源码、运行说明及可导入示例。

## 如何体验

下载或克隆仓库后，进入 `政策智答_交互原型演示包/政策智答_交互原型`，双击 `打开原型.cmd`，或使用 Chrome / Edge 打开 `dist/index.html`。无需安装依赖或配置模型密钥。

建议按以下顺序演示：

1. 查看知识库中的政策文件与版本。
2. 提问申请条件或材料清单，点击引用核对原文。
3. 发布政策修订版，重新提问并对比答案。
4. 查询历史时点，查看对应旧版政策。
5. 在技能广场创建并调用自定义技能。

## 原型说明

原型采用 HTML、CSS 和 JavaScript 实现，数据保存在当前浏览器。问答通过预设规则演示，尚未接入真实大模型、向量检索、OCR 和服务端权限系统。内置政策及机构均为虚构示例，不作为实际办事依据。
